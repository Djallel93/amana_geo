📖 GEO API - Documentation

Bienvenue dans la documentation de l'API GEO pour AMANA

🎯 Fonctionnalités

  • ✅ Géocodage d'adresses françaises
  • ✅ Recherche de quartiers par proximité
  • ✅ Calcul de distances géographiques
  • ✅ Gestion des villes, secteurs et quartiers
  • ✅ Rapports géographiques automatiques

🚀 Démarrage rapide

  1. Créer vos villes : 📦 AMANA → ➕ Créer → 🏙️ Nouvelle ville
  2. Créer des secteurs pour chaque ville (Nord, Sud, Est, Ouest, Centre)
  3. Créer des quartiers avec leurs coordonnées
  4. Géocoder automatiquement : 🗺️ Géolocalisation → 📍 Géocoder les quartiers
  5. Générer un rapport : 🧪 Tests & Outils → 📈 Générer rapport

💡 Astuces d'utilisation

🔍 Géocodage automatique

Lors de la création d'un quartier, utilisez le bouton "Géocoder automatiquement" pour obtenir les coordonnées GPS sans les saisir manuellement.

💾 Cache intelligent

Le système met en cache les résultats de géocodage pour économiser votre quota Google Maps (1000 requêtes/jour).

📊 Rapports réguliers

Générez des rapports mensuels pour suivre l'évolution de votre couverture géographique.

🔄 Centroïdes automatiques

Les coordonnées des secteurs peuvent être calculées automatiquement en fonction de leurs quartiers.

🛠️ Outils disponibles

Outil Description
📍 Géocoder les quartiers Géocodage en masse des quartiers par ville ou secteur
🏙️ Géocoder les villes Trouve les coordonnées du centre de chaque ville
🔍 Trouver quartier Recherche le quartier le plus proche d'une adresse
🎯 Quartiers dans un rayon Trouve tous les quartiers autour d'un point
🔄 Calculer centroïdes Calcule le centre géographique des secteurs
📈 Générer rapport Crée un rapport complet avec graphiques

🔐 Sécurité

L'API est protégée par un système d'authentification hybride :

  • Interface UI : Vérification de l'email
  • API REST : Tokens d'accès

Gérez les accès via : 📦 AMANA → 🔐 Gérer l'authentification

📞 Support

Pour toute question ou problème :

  • Consultez les logs : Extensions → Apps Script → Exécutions
  • Lancez les tests : 📦 AMANA → 🧪 Tests & Outils → ✅ Lancer tous les tests
  • Vérifiez la configuration : 📦 AMANA → ⚙️ Configuration

  • Nettoyez le cache manuellement si vous modifiez beaucoup de données
